# tre-shakeable
У разработчика должна быть возможность из всей библиотеки взять только `Result` и в бандл при этом не должно попасть ничего лишнего.  

# простота
из коробки должны работать простые методы OK, ERR, RES - закрывающие 80% юзкейсов.  

# chains
из коробки должны работать синхронные и асинхронные цепочки

# полиморфизм
А также разработчик должен иметь возможность лигитимно переопределить поведение всего api
